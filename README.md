# ERPNext Order-to-Cash Governance, Migration & QA Audit

A reproducible portfolio project for migrating the real UCI Online Retail II dataset into an
ERPNext order-to-cash model with controlled rejection, audit lineage, reconciliation, role
governance, UAT, and reporting.

> The repository uses public retail data for analytical demonstration. ERP posting evidence and
> deployment status are reported only after the corresponding environment has been executed.
